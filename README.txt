ASTRA'S SKY HOP

This is a standalone static web game. The published version uses only the files
in this folder and does not need a server, build step, or external game library.

PLAY LOCALLY
Open index.html in Chrome. Keep style.css, game.js, and the assets folder beside
it so the character and dialogue clips load.

CONTROLS
Tap or click the game, or press Space, to flap. The Start Game and Restart
buttons also work with touch and mouse.

ASSETS
The bird's face is a transparent crop from the supplied game image. Dialogue 1
and Dialogue 2 were supplied as audio clips, so they play on flap and game over.
